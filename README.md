<h1 align="center">Academic Repro</h1>

<p align="center"><strong>从论文图表与计算结果，回到可信、可运行、可检验的研究过程</strong></p>
<p align="center">简体中文 · <a href="README.en.md">English</a> · <a href="academic-repro/SKILL.md">Skill 规范</a></p>

Academic Repro 是面向 Codex 的学术图表与研究结果复现 Skill。它复现图表背后的仿真、训练、测量、统计或算法过程，并判断生成结果能否替换论文原图表、继续支撑同一局部论点。目标不是临摹像素，也不是把一次成功运行写成对整篇论文的证明。

## 安装与调用

```text
使用 $skill-installer 安装 https://github.com/SciToolsmith/academic-repro/tree/main/academic-repro
```

```text
使用 $academic-repro 复现这篇论文的图 1、图 6 和表 2；结果应能替换原图表而不改变相邻正文的论点。
```

以上两段是输入到 Codex 对话中的指令，不是终端 Shell 命令。

可提供论文与目标图表、论文与图表编号，或仅提供目标图片。仅有图片时，Skill 只重建像素中可以可靠识别的内容，不会把重绘称为原始实验复现。

## 核心判断

Academic Repro 先判断目标**如何产生、在论文中充当什么证据**，而不是只看外形：

- 仿真、训练、搜索、优化或统计产生的图、定量表、模型结构和拓扑，属于计算结果；即使看起来像结构示意图，也应复现其生成过程。
- 参数表和场景表通常是复现输入；定性文献比较、符号表和能力清单属于说明内容。
- 只有作者为解释理论、流程或机制而绘制、且本身不是计算输出的示意图，才交由科研示意图工具重建。
- 一张表可以同时含有输入列、计算结果列和说明列，应按列或单元分别判断。

原始代码和数据齐全时优先直接重算。独立实现前，仅当作者或论文明确指向的代码可能改变路线或证据边界时，进行一次有界检查。缺少不可恢复的原始材料时，构建能支撑论文局部论点的最小可信机制，或用独立数据、推导和实现进行替代验证；证据不足时明确给出边界或阻断。不会为贴近原图拟合曲线、事后挑选随机种子或伪造作者未报告的参数。

## 什么算通过

复现结果通过所有适用的科学门槛才算通过：

1. **可信生成**：来自透明、可运行的数据、方程、模型或算法链，而不是对发表图片反向拟合。
2. **方法有效**：数据处理、目标量、比较方式、实验单位、不确定性和适用条件满足该研究类型真正需要的有效性要求。
3. **论点保持**：冻结的标准得到结果支持，且结论不超出当前证据路线能够证明的局部范围。

只有用户要求替换原图或忠实重建时，才额外检查**视觉语义保持**：保留承载比较关系的图表形式、子图关系、坐标、单位、图例映射、分组和归一化；不要求配色、字体、间距或逐像素一致。

阈值只有在来自论文、用户要求、方法有效性条件或可靠领域依据时才是硬门槛。任意设定的相似度或“收益保持率”可以用于诊断，不能单独把科学上可替换的结果判为失败。

同一实验产生多个目标时，共享数据划分、基础场景、模型检查点和指标定义等固定条件，同时保留渗透率、拓扑、噪声或方法等有意变化。共享上游失败会影响依赖目标，某一目标自身失败不会掩盖其他目标的结果。

## 交付

默认只交付客户真正需要的内容：最终图或表、生成它的最终代码、代码必需且不可再生的输入、最小依赖说明，以及一份含结论、准确复跑命令、关键假设和实质限制的短 README。搜索记录、调试日志、过程草稿、验证清单和无关中间文件留在内部；正式交付或声称“已验证可复跑”前，才要求在干净副本中复跑。

证据强度按风险分级：只读评估不创建记录；普通单目标复现保留一份紧凑摘要；需要机器核验的正式包才绑定证据记录和干净复跑收据；随机性、数据划分、泄漏、重复试验等专项检查，只在它们可能改变结论时启用。这样不会为了填满通用模板而消耗不必要的时间和 token。

Skill 的科学判断不依赖特定操作系统。仓库内的辅助脚本需要 Python 3.10+，当前面向 Linux/macOS；完整 Windows 流程暂不支持。PDF 自动定位另需 `Pillow`、`pdfplumber` 和 Poppler，目前自动识别英文 `Fig.`/`Figure` 加正整数；中文图号、补充图、表格、子图或其他复杂标签可由用户提供目标文件或使用经审核的人工标签绑定。完整规则见 [Skill 规范](academic-repro/SKILL.md)。

## 本地开发与验证

```bash
git clone https://github.com/SciToolsmith/academic-repro.git
cd academic-repro
python -m pip install -r academic-repro/requirements.txt
python -m unittest discover -s tests -v
```
